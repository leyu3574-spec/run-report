# 🏃 跑步年度报告

**本地版 Strava 年报**：导入 Garmin 数据，一键生成你的跑步故事 —— 月跑量、配速趋势、PB 榜、训练类型、目标追踪，全部离线完成。

![在线试用](https://img.shields.io/badge/在线试用-GitHub_Pages-FF5A3C) ![单文件](https://img.shields.io/badge/单文件-零安装-success) ![离线](https://img.shields.io/badge/离线-数据不出本机-blue)

👉 **在线试用**：https://leyu3574-spec.github.io/run-report/

## ✨ 功能

- 📊 **月跑量柱状图**：每个月跑了多少，一目了然
- ⚡ **配速趋势线**：每一次跑步的平均配速 + 移动平均趋势，曲线向上 = 越跑越快
- 🟩 **跑步热力图**：GitHub 绿格子风格的每一天
- 🏆 **PB 榜**：1K / 5K / 10K / 半马，按距离自动匹配最快成绩
- 🏷️ **训练类型分布**：从活动名称识别基础 / 间歇 / 阈值 / 恢复……
- 🎯 **目标追踪**：比如"5K sub20"，自动计算还差多少
- 🔥 **连续跑步天数**、最长单次、总时长
- ⬇️ **生成年度跑步卡片**（1080px PNG，直接发小红书 / 朋友圈）

## 🚀 使用

1. 打开 **Garmin Connect 网页版**（connect.garmin.cn）→ 左侧导航 **活动** → **所有活动**
2. ⚠️ **先向下滚动**把想统计的活动都加载出来（列表是懒加载的，没滚动到的不会被导出）
3. 点击列表 **右上角的导出箭头 → 导出 CSV**，文件直接下载，无需等邮件
4. 把 CSV 拖进本工具，报告自动生成（非跑步活动自动过滤）
5. 没有 Garmin？点 **✨ 先看演示数据** 体验，或 **⬇️ 下载 CSV 模板** 手填

> 🔒 **隐私**：纯前端单文件应用，所有解析和统计都在你的浏览器本地完成，不上传任何数据。

## 🛠️ 技术

- 零依赖，单 HTML 文件
- 图表全部手绘 Canvas（坐标轴、网格线、移动平均趋势线）
- CSV 解析兼容 Garmin Connect 导出格式（自动识别距离/时间/配速/心率列，支持公里/英里/米）
